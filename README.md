# Gonzalo Giovannelli

I design and build the operating system of a business where none exists yet: industrial
engineering method, executed today through AI-structured work.

The setting changes and the problem does not. Real estate development and co-investment,
food production, manufacturing, international logistics: an operation running on paper,
memory or scattered spreadsheets, and nobody able to see it whole.

## How I work

Measure before deciding, break the constraint into its factors and move the one nobody is
touching, then build the control that keeps the fix in place. That is DMAIC, learned as an
industrial engineer and applied on a production floor years before I certified it.

Since April 2026 that method runs on AI. I did not learn to code: I specify, structure and
govern systems built with Claude Code, with written rules, automated checks and a decision
log, so the output is the same whoever produces it.

## Work you can see

- **[claude-code-os](https://github.com/gonzalogiovannelli/claude-code-os)**:
  the governance layer of the operating system I built at work, made generic: written

  trusting memory.
- **[banca-personal-api](https://github.com/gonzalogiovannelli/banca-personal-api)**:

- **[asesor-fiscal-ia](https://github.com/gonzalogiovannelli/asesor-fiscal-ia)**:
  run your personal taxes with Claude Code: an intake interview, obligations researched

- **[restaurant-management-system](https://github.com/gonzalogiovannelli/restaurant-management-system)**:
  a custom management system I built and ran for a restaurant and wine shop from 2023 to
  2026. Sales pulled from the Maxirest API, purchases, cash and wine stock in one place, one
  Power BI view on top. Data anonymised.
- **[Continuous-Improvement](https://github.com/gonzalogiovannelli/Continuous-Improvement)**:
  DMAIC on a food production line. From about 6 to about 15 tonnes a day with roughly
  USD 600 of changes, instead of the new lines that had been planned.
